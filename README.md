# Kairos Planner

Una aplicación completa de planificación y gestión de productividad diseñada para ayudarte a organizar tu tiempo y tareas de manera eficiente.

## 🚀 Características

Kairos Planner es una aplicación "all-in-one" que combina múltiples funcionalidades de productividad en una sola plataforma:

- **Gestión de Tareas**: Organiza, prioriza y da seguimiento a tus tareas diarias
- **Planificación de Tiempo**: Optimiza tu agenda con herramientas de planificación inteligente
- **Seguimiento de Proyectos**: Gestiona proyectos complejos con hitos y plazos
- **Calendario Integrado**: Visualiza tus compromisos en un calendario interactivo
- **Notificaciones y Recordatorios**: Nunca pierdas una fecha importante

## 🚀 Instalación y Uso

### Requisitos Previos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Para el backend (futuro):
  - Java JDK 17 o superior
  - Maven o Gradle
  - Base de datos compatible

### Configuración del Frontend
1. Clona el repositorio:
   ```bash
   git clone [URL-del-repositorio]
   cd kairos-planner
   ```

2. Abre `index.html` con Live Server en VS Code o directamente en tu navegador
